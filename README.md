# Predicting Student Performance Using Data Science

A Machine Learning project that predicts student academic performance using statistical analysis, exploratory data analysis (EDA), and classification models.

## Project Overview

This project aims to predict student academic performance using Data Science, Statistical Analysis, and Machine Learning techniques. The analysis identifies key factors affecting student success and develops predictive models to classify students based on their performance.

## Objectives

* Analyze factors influencing student academic performance.
* Identify significant relationships between student behavior and grades.
* Build predictive models to classify student performance.
* Compare machine learning models and evaluate their effectiveness.

## Dataset

The dataset contains student demographic, social, and academic information, including study habits, absences, failures, social activities, and final grades.

## Tools and Technologies

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib

## Methodology

### 1. Data Loading and Cleaning

* Loaded the dataset from CSV files.
* Checked for missing values and data inconsistencies.
* Prepared data for analysis.

### 2. Exploratory Data Analysis (EDA)

* Analyzed grade distributions.
* Generated correlation heatmaps.
* Examined relationships between study habits and academic performance.

### 3. Statistical Analysis

* Performed hypothesis testing using a T-test.
* Compared academic performance between students with different social activity levels.
* Found statistically significant differences in performance.

### 4. Feature Engineering

* Converted final grade (G3) into a binary target variable.
* Encoded categorical variables using Label Encoding.
* Standardized numerical variables using StandardScaler.

### 5. Model Building

Implemented and compared:

* Logistic Regression
* Random Forest Classifier

### 6. Model Evaluation

Evaluated models using:

* Accuracy Score
* Precision
* Recall
* Confusion Matrix

## Key Findings

* Study time positively impacts student performance.
* High absenteeism negatively affects academic outcomes.
* Previous failures strongly influence future performance.
* Excessive social activity may reduce academic achievement.
* Random Forest outperformed Logistic Regression in prediction accuracy.

## Results

Important predictors of student success:

* Study Time
* Absences
* Previous Failures
* Social Activity (Go Out)

The Random Forest Classifier achieved the best overall performance and provided reliable predictions for student outcomes.
